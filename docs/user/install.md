# Install and start Puff Collab

Puff Collab currently runs from this repository's source. Follow the [README setup and usage guide](../../README.md#start-the-desktop-app) to install dependencies, build the desktop app, authenticate a coding provider, and start working on a local project.

Use a dedicated data directory such as `~/.puffcollab`. The `T3CODE_HOME` setting remains available for compatibility. The upstream `t3` package, Homebrew cask, Windows package, and app-store downloads install T3 Code rather than this fork.

The desktop app connects to its bundled local server automatically. Optional [hub linking](../../README.md#link-your-computer-to-a-hub) uses a GitHub account and a fresh hub code. Browser pairing is a separate remote-access feature; it is not required to launch or use the native application.
